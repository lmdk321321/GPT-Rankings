## 🧪 评测标准


1. **模型与输出一致性：**模型身份核对、指令遵循、推理/代码任务基准，以及可能的响应截断。
2. **可用性与稳定性：**成功请求率、限流与错误率、多时段可用性。
3. **响应体验：**首字延迟、整体响应时间、吞吐及高峰期波动。
4. **价格透明度：**实际计费单位、账单可验证性、价格变动记录。
5. **安全与合规：**隐私政策、密钥与日志处理、服务条款、主体信息。
